# Media fixtures

Nothing binary is committed here. Every media input used by the offline pipeline is
generated at run time, so there is no real product image, person, voice, music or font in
the repository.

| Fixture | Generated by | Provenance |
|---|---|---|
| Product still (JPEG, 540x960) | `EndToEndPipelineTests` via SkiaSharp | Synthetic shapes drawn by the test; no real product |
| Mock narration (WAV tone) | `MockVoiceProvider` | Sine tone, not speech; length follows the text |
| Mock AI motion clip (MP4, 720x1280, 3 s) | `MockClipGenerator` via FFmpeg `testsrc2` | FFmpeg synthetic test pattern |
| Caption font | the host | Never committed; `CAPTION_FONT_FILE` points at a licensed file and its SHA-256 becomes the font fingerprint |

Rules:

- A fixture added later must record its source, licence and an owner attestation here, and
  must not contain personal data, a real customer product or an unlicensed asset.
- Mock output is labelled `MOCK MODE` (`GET /api/v1/system/mode`) and is never evidence
  that a cloud provider, price or voice works.
- The smoke command is `make smoke-mock` (optionally `make smoke-mock ROUNDS=3`).
